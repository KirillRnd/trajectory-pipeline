# Источники освобождения времени

Неизменённые копии пользовательских MATLAB-наработок из
`D:/MATLAB/asteroid_venus_AI`, перенесены 10 ноября 2026 года.

- `venus_cycle.m`: независимый перенос одной опоры на каждую дату;
  свободный X(8), закреплённый X(9), fmincon с граничными равенствами.
- `fun2min_core.m`, `fun2min_J.m`, `fun2min_border.m`: интегрирование,
  расход и граничные условия для изменяемого времени прибытия.
- `apophis_ummp_bangbang_fmincon_full_costates_tof.m`: дополнительная
  наработка с полными сопряжёнными и временем, штрафной целевой функцией.

Основой нового корректора служит ограниченная оптимизация Венеры.
Частные временные границы старой миссии и возврат неудачного начального
приближения как результата не перенесены. Оригинальные файлы здесь —
источники алгоритма, не исполняемый компонент Linux-пайплайна.

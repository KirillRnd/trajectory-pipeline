# Trajectory Pipeline

Единый комплекс расчёта, проверки и визуализации межпланетных перелётов
к планетам и астероидам. Компоненты можно использовать самостоятельно
или соединять через общий управляющий интерфейс.

**[Вход в скил и карта всех компонентов](.agents/skills/trajectory-pipeline/SKILL.md)** ·
[Справочник команд и моделей](trajectory_pipeline/README.md) ·
[Состояние и результаты проверок](PIPELINE_STATUS.md)

## Состав комплекса

| Компонент | Назначение |
|---|---|
| Эфемериды | Локальные состояния тел, контроль покрытия и точности |
| ИРТ / ILTT Toolbox | Начальное энергетическое решение |
| KIAM Toolbox / kiam-astro | Отдельный базовый компонент: JPLEPH и независимая Fortran-сверка ПСИ; готовая неизменённая зависимость |
| Продолжение по гиперболическому избытку | Начальная дополнительная скорость и её оптимизация |
| Метод Пазова → ПСИ | Ограниченная тяга, переменная масса, активные и пассивные участки |
| УММП | Продолжение проверенной ПСИ к историческому закону двигателя |
| Отлёт, захват, сшивка | Раскрутка/РБ и скрутка/импульсный захват; четыре сочетания |
| R-преобразование | Перенос сопряжённых между узлами, координаты корректора, чувствительность |
| Массовые расчёты | Независимый перенос по датам, матрицы двигателей, масс и геометрий |
| Проверка и диагностика | Приёмка участков и стыков, аудит параметров, причины остановки |
| Визуализация | Общие и локальные траектории, профили тяги и массы, события импульсов |

## Быстрый запуск

Нужны Git и Docker Compose с Linux-контейнерами `linux/amd64`.
Все команды ниже выполняются из корня клона. Windows Python не используется.

```sh
git clone https://github.com/KirillRnd/trajectory-pipeline.git
cd trajectory-pipeline
docker compose build pipeline
docker compose run --rm pipeline --help
docker compose run --rm pipeline coverage Earth Mars Apophis Ceres
docker compose run --rm pipeline render data/references/ummp156 --output output/pipeline/ummp156
```

Окружение устанавливает зафиксированные зависимости и официальный KIAM Astro
6.1.6 Linux wheel со встроенным Fortran. SHA256 wheel проверяется при сборке.
Первичная сборка требует сети; штатные расчёты работают без сети.
Расширение локальных эфемерид выполняется отдельным сервисом `ephemerides`.
Роль KIAM Toolbox, собственные адаптеры и самостоятельное использование
описаны в [инструкции компонента](.agents/skills/trajectory-pipeline/references/kiam-toolbox.md).

Пример новой составной миссии с настраиваемой НОО и конечной орбитой Марса:

```sh
docker compose run --rm pipeline solve configs/orbital_modes/mars_impulse_impulse_dry60.json --output runs/mars_example
docker compose run --rm pipeline verify-orbital runs/mars_example
docker compose run --rm pipeline render-orbital runs/mars_example --output output/pipeline/mars_example
```

Проверки комплекса:

```sh
docker compose run --rm --entrypoint python pipeline -m unittest discover -s tests -v
docker compose run --rm --workdir /tmp -e PYTHONPATH=/workspace/components/pazov:/workspace --entrypoint python pipeline -m unittest discover -s /workspace/components/pazov/tests -v
```

## Структура репозитория

- `.agents/skills/trajectory-pipeline/` — единый скил и инструкции компонентов.
- `trajectory_pipeline/` — общий Python-код и командный интерфейс.
- `ILTT/`, `components/` — необходимые исходные методы и материалы их происхождения.
- `configs/` — миссии, четыре сочетания манёвров и планы массовых проверок.
- `data/ephemerides/`, `data/references/` — локальные эфемериды и эталоны.
- `data/benchmarks/`, `reports/` — сохранённые серии, первичные результаты и отчёты.
- `third_party/kiam_astro/` — неизменённый Linux wheel и документация API.
- `references/` — теоретические материалы, исторические уравнения и образец графика.
- `tests/`, `docker/`, `compose.yaml` — проверки и воспроизводимое окружение.
- `runs/`, `output/pipeline/` — новые результаты; содержимое не добавляется в Git автоматически.

Клон содержит данные для штатных тестов и архивной проверки без соседних
проектов. Происхождение выделенной версии описано в [MIGRATION.md](MIGRATION.md).
Исторические метаданные сохраняют исходные пути и версии запусков.

## Подтверждённая область работы

Широкая серия из 15 постановок дала 6 полных ПСИ, 8 частичных результатов
и 1 программную ошибку. Отчёт сохраняет конкретные остановившиеся этапы.
Четыре сочетания орбитальных манёвров приняты на контрольном Марсе с сухой
массой 60 кг; широкая совместная приёмка этих манёвров ещё не выполнена.
Переход к УММП проверен на Апофисе 156 кг выше порога отключения 200 Вт.
Луна исключена из целей общего метода.

Отделение репозитория не расширяет подтверждённую область сходимости.
Проверка опубликованного клона выявила платформенную чувствительность
пересчёта прежней марсианской скрутки: локально 63/63 теста, на GitHub 62/63.
Незавершённая проверка и исправление временной сетки Бенну описаны в
[отчёте выделения](reports/repository_extraction.md).
Полные результаты, ограничения и нерешённые вопросы — в
[PIPELINE_STATUS.md](PIPELINE_STATUS.md).

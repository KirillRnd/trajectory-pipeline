# CR3BP: самостоятельный компонент аппроксимаций

Применять при запросах про CR3BP, ограниченную круговую задачу трёх тел,
приближения семейств орбит, L1/L2/L3, L4, S3, C1/C2, периодические орбиты.
Сначала читать [состав, диапазоны и ограничения](../../../../components/cr3bp/README.md).

Исходный код и очищенные кодовые блокноты находятся в `components/cr3bp/`.
Не запускать массово исторические скрипты: они могут сразу начать обучение
PySR и читать отсутствующие датасеты. В среду не добавлять PySR ради вызова
готовых формул. Статьи и обучающие данные не перенесены по поручению пользователя.

Рабочий самостоятельный API:

```sh
docker compose run --rm -T --entrypoint python pipeline -c "from trajectory_pipeline.cr3bp import seed; print(seed('L1', 0.8))"
```

Поддержаны L1/L2/L3, L4_v2/L4_v3 и S3 с исходными μ и демонстрационными
диапазонами. C1/C2 доступны как исходные функции, без подтверждённой области
точности. Проверки и первичные численные результаты описаны в README
компонента и `reports/cr3bp/verification.json`.

Всегда сообщать: это `approximation_only`, нормированные вращающиеся
барицентрические координаты, а не принятая миссия или точная периодическая
орбита. Для продолжения нужны коррекция и независимая проверка замыкания.
Перевод в SI/инерциальную систему и сшивка с ПСИ не реализованы. Не передавать
выход напрямую в межпланетный контроллер. Не менять μ фиксированной
аппроксимации ради другого тела. Наличие исходной системы Земля–Луна
не отменяет исключение Луны из целей общего метода.

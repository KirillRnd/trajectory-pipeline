# KIAM Toolbox / kiam-astro

Самостоятельный базовый компонент [траекторного комплекса](../SKILL.md),
на одном уровне с ILTT Toolbox. KIAM Astrodynamics Toolbox подключается
через готовый пакет `kiam-astro`. ILTT и KIAM имеют разные роли и интерфейсы.

## Зависимость и расположение

- Официальный Linux wheel версии 6.1.6 с упакованным Fortran находится в
  [third_party/kiam_astro](../../../../third_party/kiam_astro/).
- Платформа — CPython 3.12, Linux amd64, glibc ≥2.38.
- SHA256 — `fe15a29c1a55cb4e8aa0867c21384f7bf6947018fa6077660b2f6cbe0294716b`.
- [Dockerfile](../../../../docker/pipeline.Dockerfile) проверяет SHA256;
  [lock-файл](../../../../docker/requirements.lock.txt) фиксирует зависимость.
- [Извлечённые исходники API](../../../../third_party/kiam_astro/extracted/)
  служат документацией. Пакет и его Fortran не изменять и не пересобирать.
  Собственные преобразования и проверки находятся в `trajectory_pipeline/`.

## Операции и точки подключения

| Операция | Вход → выход | Реализация комплекса |
|---|---|---|
| Эфемериды основных тел из JPLEPH | Тело, центр, JD TDB → геометрическое состояние SI в ECLIPJ2000 | `ephemerides.Ephemerides.state`, нативный `kiam.planet_state` |
| Контроль уравнений и управления ПСИ | Сохранённая физическая ПСИ → ошибки соответствия и `passed` | `kiam_verification.verify_kiam_psi`, нативный `kiam_astro.optimal` |
| Контроль нецентрального поля | Сохранённое состояние и модель поля → сравнение ускорений | `kiam_verification.verify_kiam_gravity`; экспериментальный лунный сценарий вне текущих целей |
| Фиксация окружения | Установленный пакет → версия в метаданных запуска | `runtime.runtime_environment` |

Эфемеридный компонент объединяет нативные данные KIAM и локальные таблицы
Horizons. Проверка ПСИ через KIAM включена в `solve`, составные миссии и
`sweep-psi`; переход `ummp` проверяет таким образом исходную ПСИ.
Финальный исторический закон УММП принимает собственный `verify-ummp`.
Совпадение с моделью KIAM для постоянных F/c не подтверждает иной закон тяги.

## Самостоятельное использование

Покрытие и выбор источника эфемерид:

```sh
docker compose run --rm pipeline coverage Earth Mars Jupiter Ceres
```

Отдельная проверка сохранённой ПСИ с осмысленным кодом завершения:

```sh
docker compose run --rm --entrypoint python pipeline -c "import json; from trajectory_pipeline.data import Trajectory; from trajectory_pipeline.kiam_verification import verify_kiam_psi; check=verify_kiam_psi(Trajectory.load('data/benchmarks/psi/earth_apophis_2029')); print(json.dumps(check, indent=2)); raise SystemExit(0 if check['passed'] else 2)"
```

Для дополнительных функций toolbox сначала читать документацию нужного API
в `extracted/`, затем добавлять адаптер в собственный код. Возможность,
существующая в стороннем пакете, становится проверенным компонентом пайплайна
после согласования единиц, модели и независимой проверки реальной задачи.

## Соглашения и ограничения

Нативные состояния KIAM переводятся из километров и экваториального базиса
в SI и ECLIPJ2000. Проверять центр тела и барицентр системы, диапазон JPLEPH
и источник, фактически выбранный адаптером. Не экстраполировать эфемериды.
Вызовы нативного поставщика состояний защищены `_KIAM_LOCK`: он использует
общие Fortran-данные и меняет рабочий каталог. Не обходить эту защиту
параллельными вызовами из новых потоков.

Нативную независимую проверку отличать от полного повторного интегрирования
и проверки граничных условий: приёмка требует всех применимых проверок.
Текущие свидетельства находятся в общих тестах `test_pipeline_foundation.py`,
`test_pipeline_physical.py` и проверках составных миссий.

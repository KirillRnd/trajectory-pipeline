# Компонент seed

Часть единого [траекторного комплекса](../SKILL.md).

Работать из корня проекта внутри Docker. Windows Python не запускать.
Постановка и формат — [документация](../../../../trajectory_pipeline/README.md),
текущие области применимости — [состояние](../../../../PIPELINE_STATUS.md).

ИРТ: `docker compose run --rm pipeline solve-irt <mission.json> --output <new-run>`.
Матрица JSON-миссий: `sweep-irt <matrix.json> --output <new-run>`.
Проверенный результат указан в `summary.json:last_result`; не предполагать,
что после возобновления он всегда называется `irt/`.
Для лунного ИРТ команда сама продолжает земное поле до Земля–Луна–Солнце.
Его `--resume` сохраняет принятый двухтельный вход и точки гравитационного пути.

Начальная скорость:
`docker compose run --rm pipeline departure <verified-result> --output <new-run>`.
Продолжение checkpoint: добавить `--resume`.
Режимы миссии: `fixed_vector`, `fixed_norm`, `bounded_norm`, `free`.
На границе шара проверять ККТ и знак множителя, внутри — p_v(t0)=0.
Команда `departure` означает продолжение по начальной скорости ИРТ,
а не физический участок от НОО с РБ. Для него использовать `solve` с
`parking_departure` через [trajectory-pipeline](../SKILL.md).
В составной миссии начальная скорость на конечном радиусе и истинный v∞
связаны энергией гиперболы; не подменять одно другим. Готовое ИРТ/ПСИ
используется как начальное приближение для нового согласования интерфейсов.
Лунное начальное приращение отсчитывается от опорной круговой орбитальной
скорости, это не гиперболический избыток у Земли.

ИРТ минимизирует квадратичное управление без физического расхода топлива.
Не выдавать его массу/пиковое ускорение за допустимую ПСИ.
Сравнивать доступные ветви начальных приближений: первое сошедшееся решение
может быть чрезмерно дорогим. Сохранять сведения о выборе ветви.

Принимать решения по независимому пересчёту, допускам в метрах/м/с и
трансверсальности. Для Луны также требуется полное поле и проверка сближений
с Землёй/Луной. Промежуточную гравитационную модель не считать готовой миссией.

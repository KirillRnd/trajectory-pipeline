# Траекторный комплекс

- Единый вход — [.agents/skills/trajectory-pipeline/SKILL.md](.agents/skills/trajectory-pipeline/SKILL.md).
  Он перечисляет все компоненты, включая визуализацию, и маршруты их совместной работы.
  Подробные инструкции компонентов находятся в `references/` этого скила.
- Текущее состояние, результаты и ограничения — `PIPELINE_STATUS.md`.
  Перед новым расчётом проверить существующие решения и принятые параметры.
- Для новой центральной задачи вход ILTT: дата старта → фаза → положительные
  угловые ветви → согласование ILTT → длительность. Не подбирать λ обратно
  по заранее назначенному времени. λ=0,75 — переключение аппроксимации,
  короткие положительные ветви разрешены. Освобождение времени — следующий
  отдельный шаг. Старые фиксированные серии не подтверждают этот вход.
- Свежая матрица по дате — `configs/search_matrix_date_v4.json`; общий дизайн
  — `configs/search_graph_fresh_iltt_v4.json`. При проверке с нуля не подменять
  холодные цепочки старыми физическими опорами. Отдельно считать согласование
  ILTT, проверенную ИРТ, промежуточную модель и принятую физическую ПСИ.
- Все вычисления, проверки и работа с Python выполняются только в Linux Docker.
  Windows Python не использовать. Сборка — `docker compose build pipeline`;
  запуск — `docker compose run --rm pipeline <команда>`.
- Исходники и данные смонтированы только для чтения. Новые результаты писать
  в `runs/` или `output/pipeline/`. Прежние серии сохранять отдельно.
- KIAM используется готовым Linux PyPI wheel с Fortran и проверкой SHA256.
  Пакет не менять и не пересобирать.
- Оценивать общий метод на фиксированных реальных постановках планет и
  астероидов, включая Цереру. Луна исключена из целей метода.
  Общие настройки не подгонять под отдельные строки.
- При остановке указывать этап, последнюю проверенную модель и причину.
  Частичный результат и несходимость не доказывают физическую недостижимость.
- Проверять соответствие двигателя, массы и дат на всех стыках. В составной
  миссии согласовывать время, положение, вектор скорости, массу и законы скачков.
- Для просмотра изображений готовить JPEG-превью: обычно 1280 px, максимум
  1600 px по длинной стороне и 200 КиБ; до четырёх изображений / 750 КиБ за раз.
  Исходные научные графики сохранять в требуемом формате.

# Продолжение ПСИ к УММП на эталоне Апофиса 156 кг

Запуск в Docker:

```powershell
docker compose run --rm --entrypoint python pipeline -m trajectory_pipeline.ummp_benchmark --output runs/ummp_apophis_156kg_benchmark
docker compose run --rm pipeline verify-ummp runs/ummp_apophis_156kg_benchmark/ummp/point_0004
```

Старт 14 февраля 2029, 12:00 TDB. Перелёт 422,661801537 суток.
Использованы исторические состояния Земли и Апофиса на границах, солнечный
гравитационный параметр из MAT, заданный стартовый вектор избытка 3 км/с
и масса 156 кг. Сухая масса 90 кг взята из проверочной конфигурации ПСИ.
Начальная ПСИ с 25 мН и (c=20) км/с построена через ИРТ, продолжение по
вектору избытка и Пазов. Из MAT взяты границы и условия сравнения.
Сопряжённые переменные и расписание тяги получены новым расчётом.
[Архивный вход](../data/references/apophis_ummp_156kg_hard_bangbang_verified.mat).

Разница расхода составляет −0,032 г. Наибольшее смещение переключения
составляет 0,073 суток. При тех же границах новый расчёт оптимизирует
израсходованную массу, включает производные тяги и расхода по радиусу
в уравнение для (p_r) и соблюдает (p_m(t_f)=0) в постановке с
интегральным критерием. Исторический решатель подбирал выполнимое
рандеву с ограничением на расход и использовал другую систему
сопряжённых уравнений. [Исторические уравнения](../references/historical_ummp/integrate_dmdt_optimal.m) ·
[Подбор эталона](../references/historical_ummp/apophis_ummp_156kg_homotopy_rendezvous.m).

Дополнительно команда `ummp` проверена на существующей ПСИ Апофиса
с современными эфемеридными границами и ограничением на модуль избытка.
Она достигла доли 1,00 с расходом 34,476809 кг. Это отдельная геометрия.
Команды `verify-ummp` и `--resume` завершились успешно. В Docker прошли
62 теста, включая сверку закона тяги и компенсированного расхода по
историческим массивам, совпадение модели при доле 0 с ПСИ и проверку
производной гамильтониана.

Данные двух прогонов находятся в
[`data/benchmarks/ummp_apophis_156kg_benchmark`](../data/benchmarks/ummp_apophis_156kg_benchmark/summary.json)
и [`data/benchmarks/ummp_apophis_jpl_v1`](../data/benchmarks/ummp_apophis_jpl_v1/summary.json).
На обеих траекториях мощность оставалась выше порога отключения 200 Вт.
При достижении порога сохраняется последняя принятая точка. Для продолжения
через порог нужны условия скачка сопряжённых на границе доступности тяги.

# Отдельная проверка программного отказа на Церере

Проверен сохранённый первый шаг заключительного функционала из
`parameter_study_analytic_v1/earth_ceres_2030__reference`. Последняя модель:
α=0.5, β=1, заданный предел тяги; пробный шаг — α=0.6. Исходный полный
запуск завершился TypeError счётчика nfev в DOP853.

Двигатель, масса, даты, граничные условия и нормировка не менялись.
Восстановлены вызовы эфемерид постановки и опорных орбит сохранённой ИРТ.
Результаты помечены `diagnostic_only` и не включены в приёмочные матрицы.

| Проверка | Исход |
|---|---|
| Холодный изолированный шаг, штатные бюджеты | Остановлен штатно по бюджетам, 17.54 с; TypeError не воспроизведён |
| Valgrind 3.24.0, PYTHONMALLOC=malloc, тот же шаг | Бюджеты инструмента ×20; остановлен штатно за 400.06 с; 0 ошибок памяти, exit code 0 |
| Первый запуск Valgrind с обычным распределителем | Намеренно остановлен для смены инструментирования; не считается завершённой проверкой |

**Причина исходного сбоя не установлена и не устранена.** Проверка покрывает
один изолированный шаг и вызовы эфемерид, а не всю историю предшествовавших
ИРТ, продолжения по избытку, Пазова и массового моста в исходном процессе.
Невоспроизведение исключения не доказывает исправления или отсутствие ошибки
во всём пайплайне. Нулевой итог Valgrind относится к завершённому главному
процессу (PID 7), а не только к дочернему процессу построения шрифтов.

В диагностическом образе не менялся пакет KIAM. Совпадение Fortran-библиотеки
в рабочем и диагностическом образах подтверждено SHA256:
`b7b0e6e3127f346f2eaaaca16a370534c870323654c3a713a0a2e36b9a1146cc`.
Valgrind сообщил об ограниченной поддержке numpy.longdouble в эмуляции;
этот запуск не используется для оценки численной точности или производительности.

В общем CLI добавлен `diagnose-step`, а не отдельный решатель Цереры.
Он восстанавливает сохранённую попытку фаз mass/limit/fuel и записывает
постановку, целевую модель, пробный параметр, источник, бюджеты, распределитель
памяти и SHA256 кода. Все 37 тестов прошли в Docker.

Архив входов, исходников команды, выводов и журналов:
`data/benchmarks/memory_probe_ceres_v1/`. Контрольные суммы — `files_sha256.json`.
Дальнейшая диагностика программной ошибки требует истории полного процесса;
подбор физической постановки или повторные неизменённые попытки одного шага
не следуют из этого результата.

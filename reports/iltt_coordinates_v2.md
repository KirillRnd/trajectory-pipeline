# Сопряжённые ↔ управляющие параметры ILTT

Проверено в Linux Docker 12.11.2026. Реализованы обратимое локальное
представление и переключение координат корректора центральной ИРТ.
Сопряжённые — основное представление решения; они не ограничиваются областью
чистых аппроксимаций ILTT.

## Что реализовано

`q=[dm,j,Omega,omega,kappa,lambda]`, `p=[p_r,p_v]`.
Прямое отображение использует исходные `get_initial_adjoint`, `R_iO`, `R_eo`
и начальную систему r/v. При обратном преобразовании сначала подбираются q.
Если чистое семейство недостаточно, сохраняется фиксированная поправка:
`p=F_ILTT(q)+delta_p`. Текущие сопряжённые сохраняются; дополнительной
оптимизируемой переменной нет. Все части представления сериализуются.

Режим корректора: `costates`, `iltt` или последовательность. Якобиан краевой
невязки считается по вариационным уравнениям с цепным правилом для ILTT.
Длительность не пересчитывается по T_a: меняются координаты той же задачи.
Граница dm=±0,5981996389807971 сохранена для локальной аппроксимации;
она не стала ограничением на канонические сопряжённые или массу ИРТ.

## Реальные проверки

| Сценарий | Маршрут координат | Результат |
|---|---|---|
| Марс, короткая ветвь, 01.01.2029 | costates → iltt → costates | Принят; максимальное изменение сохранённой траектории 1,38 мм; изменение J −2,78e−16 |
| Апофис, 15.06.2029, переход от ApophisNew к полным эфемеридам | costates → iltt → costates | Принят; ошибка восстановления сопряжённых 0; траектория и J совпали с обычной коррекцией |
| Тот же переход Апофиса | iltt → costates | Принят; отличие траектории от обычного корректора 1,94 мм; изменение J 2,69e−17 |
| Марс, перенос на 02.01.2029 | iltt → costates → iltt → costates | Принят в тесте; первый ILTT-корректор выполняет несколько итераций по новым границам |

В Апофисе после коррекции в сопряжённых чистое обратное отображение оставляло
ошибку 0,001913 в нормированных сопряжённых. Сохраняемая поправка устранила
её полностью без изменения физического решения. Это проверка именно того
случая, где нельзя отказывать в переключении из-за границы аппроксимации.
Предварительный вариант без поправки остановился на переходе источников;
он заменён этим вариантом и не является текущим ограничением метода.

В маршруте `iltt → costates` ILTT снижает невязку, но остаётся на ~0,001;
сопряжённые доводят её до 1,15e−14. Не объявлять этап ILTT сам по себе принятым
по сообщению optimizer_success. Независимая ошибка положения финальных
траекторий: Марс 1,95 м, Апофис 1,40/1,21 м; скорости <5,4e−7 м/с.

17 тестов прошли: 6 новых тестов переключения, 8 регрессионных тестов источников,
перехода и ИРТ, 3 теста прежнего R-преобразования. Проверены короткое/длинное
семейство, полная запись/восстановление с поправкой, численный Якобиан,
изменённые реальные границы, отсутствие клиппинга и ошибочные режимы.

## Воспроизведение

```sh
docker compose run --rm pipeline recoordinate-irt data/benchmarks/mars_short_psi_2029jan01/initial_chain/stage_irt/irt --coordinates costates iltt costates --output runs/my_mars_switch

docker compose run --rm pipeline reconcile-irt data/benchmarks/apophis_orbit_sources_v1/2029-06-15/early/irt --sources configs/apophis_full_sources.json --coordinates costates iltt costates --output runs/my_apophis_switch
```

[Архив принятых результатов](../data/benchmarks/iltt_coordinates_v2/),
[инструкция](../.agents/skills/trajectory-pipeline/references/iltt-coordinates.md).
Результаты не доказывают преимущество ILTT по скорости или сходимости во всех
случаях. Нелинейный переключатель пока подключён к центральной ИРТ;
корректоры избытка/Пазова/ПСИ и свободного времени отдельно не перерабатывались.

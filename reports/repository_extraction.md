# Проверка самостоятельного репозитория

Проверено 8 ноября 2026 года в Linux Docker, из отдельной папки
`trajectory-pipeline`. Исходный смешанный проект не монтировался в контейнер.
После фиксации переноса проверка повторена на чистом дереве, извлечённом
через `git archive`, без незакоммиченных файлов рабочего каталога.

Тесты проверяют реальные сохранённые состояния, аппаратные параметры,
сшивки массы/времени/вектора скорости, отклонение подменённых параметров,
независимый пересчёт, преобразования R и закон УММП.
Широкие численные матрицы при выделении заново не оптимизировались.

Проверенная расчётная ревизия —
`16432de6a27d197cdc73d5b5b35d1602264df4d2`. Последующие изменения выделения
касаются описания KIAM как отдельного компонента, сводки, манифеста и этого
отчёта. Расчётные Python-модули совпадают с исходным рабочим снимком побайтно.

## Границы результата

Подтверждена самостоятельность перенесённого набора и сохранность прежних
численных результатов. Известные ограничения сходимости широких серий,
порог отключения УММП и отсутствие широкой совместной приёмки орбитальных
манёвров сохранены в [сводке проекта](../PIPELINE_STATUS.md).
Первичная установка сторонних Python-зависимостей требует сети;
обычные расчёты используют локальные данные и сервис без сети.

В репозиторий добавлена автоматическая Docker-проверка при push и pull request.
Её удалённый статус следует смотреть отдельно от приведённой локальной проверки.

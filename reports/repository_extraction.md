`trajectory-pipeline`. Исходный смешанный проект не монтировался в контейнер.

через `git archive`, без незакоммиченных файлов рабочего каталога.

## Проверка на GitHub и оставшийся отказ

GitHub успешно собрал Docker-окружение с нуля и установил зависимости.
Первый запуск выявил два отказа, не проявившихся в локальном Docker.

1. **Бенну, восстановление точной ПСИ.** Различные безразмерные узлы старой
   сетки и нового переключения округлялись в одинаковый отсчёт SI. Возникало
   нарушение строгого возрастания времени. Исправлено в `0927d22`: объединение
   учитывает экспортируемые секунды и сохраняет точные новые переключения.
   Добавлена проверка на сетке реальной траектории Бенну с соседними машинными
   представлениями времён. Она и восстановление ПСИ прошли на GitHub.
2. **Прежний артефакт РБ → Марс → скрутка.** На GitHub независимый пересчёт
   захвата дал 16,504634 м и 0,010898122 м/с. Порог по скорости равен 0,01 м/с,
   поэтому сохранённая миссия отвергнута. Стыки, РБ, внешняя ПСИ, KIAM и
   массовый баланс прошли. Это остаётся открытым вопросом численной точности
   старого планетоцентрического расчёта.

Последняя удалённая проверка расчётной версии `0927d22` — **62 успешных теста
из 63, один отказ**. [Запуск GitHub](https://github.com/KirillRnd/trajectory-pipeline/actions/runs/42466046680),
[полная диагностика оставшегося отказа](repository_extraction/ci-capture-failure.log).
Удалённый этап тестов Пазова был пропущен вследствие предыдущего отказа;
его 36 тестов прошли локально. Автоматическая проверка оставлена с явным
отказом этого архивного сценария; тест и допуски не ослаблены.

Локальная финальная проверка после исправления временной сетки — **63/63**,
51,032 с. [Журнал](repository_extraction/final-pipeline-tests.log).
Различие исходов локальной и удалённой проверки сохраняется явно.

Диагностическая запись той же скрутки в полярных координатах при уменьшении
локальной погрешности LSODA дала для артефакта со стартом с НОО расхождение
19,15–25,55 м и 0,01265–0,01688 м/с. Это дополнительное свидетельство
чувствительности численной проверки, а не новый принятый расчёт.
[Измерения](repository_extraction/capture_polar_probe.json) и
[код диагностики](repository_extraction/capture_polar_probe.py) сохранены.
Архивные массивы, параметры миссий и пороги приёмки не изменялись.

Отделение репозитория завершено. Для устойчивой приёмки прежней связки
нужно отдельно уточнить точность построения и независимого воспроизведения
планетоцентрической скрутки, затем повторить проверку на разных платформах.

## Границы результата

Подтверждена самостоятельность перенесённого набора и сохранность прежних
численных результатов. Известные ограничения сходимости широких серий,
порог отключения УММП и отсутствие широкой совместной приёмки орбитальных
манёвров сохранены в [сводке проекта](../PIPELINE_STATUS.md).
Первичная установка сторонних Python-зависимостей требует сети;
обычные расчёты используют локальные данные и сервис без сети.

В репозиторий добавлена автоматическая Docker-проверка при push и pull request.
Её удалённый статус следует смотреть отдельно от приведённой локальной проверки.

# Общий аудит траекторного комплекса — 12 ноября 2026

Заключительный прогон в Linux Docker: **131/131 тестов комплекса**, **36/36
тестов исходного компонента Пазова**. Численные допуски не ослаблялись.
Это проверка компонентов и маршрутов, не обещание сходимости любой геометрии.

## Сквозные результаты

ApophisNew → полные эфемериды → ПСИ: **15.06.2029**, T=351,828804 суток,
204 кг начальная масса, 140 кг сухая, F=0,036 Н, c=11767,98 м/с.
Расход **34,666144 кг**, конечная масса **169,333856 кг**. Параметры проверены
относительно запроса, уравнения — независимым интегратором и KIAM.

Составной Марс: 156 кг на исходной орбите, контрольный сухой остаток 60 кг,
исходная межпланетная длительность 500 суток, общий интервал [499;501].
Орбиты и двигатели взяты из `orbital_modes_v1/dry60` без подгонки по сочетаниям.

На сочетание выполнено пять вариантов. Первично принято 19/20; один отказ
был вызван округлением двух близких времён после добавления длительной
раскрутки. Исправлены сборка и независимая проверка общей сетки; повтор
сохранён отдельно в `rounding_fixed` и принят. Старый отказ остался в журнале.
Исходные локальные сетки не менялись. Для выбранных миссий временная невязка
стыков 0 с, ошибка положения на отлёте ≤0,048 м, скорости ≤2,3·10⁻¹³ м/с.
Топливо внешнего РБ в расход КА не включено.

`optimizer_success=false`: число итераций ограничивалось для проверки связок.
Это принятые изменённые длительности, **не доказанные минимумы**.

Повторно приняты **17/17** сохранённых физических ПСИ широкой серии, включая
Цереру, с независимым интегрированием и KIAM. Это повторная приёмка, а не новый
холодный поиск всех 42 постановок. Параллельная серия 79 Апофисов имеет свой
[отчёт](apophis_new_full_psi_v1.md); её результаты не смешаны с этим аудитом.

## Артефакты и воспроизведение

[Архив](../data/benchmarks/pipeline_audit_2026_11_12/README.md) содержит выбранные
составные миссии, контроль округления, переход источников, УММП, ранний sweep,

```sh
docker compose run --rm -T --workdir /tmp -e PYTHONPATH=/workspace/components/pazov:/workspace --entrypoint python pipeline -m unittest discover -s /workspace/components/pazov/tests -v
```

## Границы принятой реализации

CR3BP предоставляет нормированные аппроксимации исходных семейств. Коррекция
периодической орбиты и перевод в отдельную физическую миссию не входят в этот
интерфейс. Луна исключена из целей общего метода. УММП и орбитальные манёвры —
отдельные продолжения ПСИ; совместной оптимизации «орбитальные манёвры + УММП +
свободное время» здесь нет. Произвольная топология дуг не является геном поиска.
Эти ограничения явно отражены в скиле; неподдержанные связки не маркируются
как готовые или принятые.

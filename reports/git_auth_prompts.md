# Локальное подавление окон входа Git

По переданному пользователем поручению для этого репозитория установлено:

```
git config --local credential.https://git.sourcecraft.dev.interactive false
```

Проверено эффективное значение URL-настройки: `false`. Origin сохраняет
хост `git.sourcecraft.dev`; URL, credential helper, глобальные настройки
и сохранённые учётные данные не менялись. Настройка хранится в `.git/config`,
не переносится коммитом в другие копии.

Согласно [официальной документации Git Credential Manager](https://github.com/git-ecosystem/git-credential-manager/blob/main/docs/configuration.md#credentialinteractive),
отключение интерактивности запрещает диалоги GCM и возвращает ошибку,
если требуется новый вход. Это относится и к ручным операциям из данной копии
для того же хоста. Сохранённые подходящие учётные данные остаются доступны.

Переданная диагностика связывала окна с фоновыми `git remote show origin`
приложения Codex, но непосредственная связь окна с процессом не доказана.
Сетевую проверку и новый вход здесь не запускали; наблюдение за следующей
фоновой проверкой приложения остаётся внешним подтверждением устранения окна.

Локальная отмена настройки при необходимости:

```
git config --local --unset credential.https://git.sourcecraft.dev.interactive
```
